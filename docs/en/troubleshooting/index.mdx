# Troubleshooting

Use the following order to isolate a failed terminal session:

1. Confirm that the `web-cli` ModuleInfo reports `Running` in the global cluster.
2. Check that the terminal Pod exists in the system namespace and reaches `Running`.
3. Confirm that the account can access the selected cluster or node.
4. Check whether the session timed out or the cluster reached its cluster terminal capacity.
